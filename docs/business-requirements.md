# ABC Retail - Business Requirements

## Objective
Build an automated cloud-based data engineering platform that processes daily business data.

## Source Systems
- ERP
- CRM
- Inventory
- Payment Gateway
- Store Management

## Input Files
- customers.csv
- orders.csv
- products.csv
- payments.csv
- stores.csv

## Functional Requirements
- Read daily files
- Validate data
- Remove duplicates
- Transform data
- Load target database
- Archive processed files
- Generate reports

## Non-Functional Requirements
- Secure
- Scalable
- Reliable
- Monitored
- Cost Optimized
